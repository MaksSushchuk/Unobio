# Writer input contract (v1.0, provisional)

The Writer receives one JSON document per run. **This contract was defined by the
Writer.** The upstream analysts' and Skeptic's real output schema was not
available when it was written. It is modelled on what the UI report screen
shows. All field access is in `writer_agent/schema.py`. If the real schema
differs, remap it there (or add an adapter in front of `parse_input`) and leave
the rest of the code as it is.

Machine-readable version: [`schemas/writer_input.schema.json`](../schemas/writer_input.schema.json).
Full example: [`fixtures/il17_crohns.json`](../fixtures/il17_crohns.json).

| Path | Required | Used for |
|---|---|---|
| `run.id`, `run.timestamp` | no | header line |
| `run.simulated`, `run.fixture_data` | no | either `true` → "Mock data – sources not verified" banner |
| `thesis.indication`, `thesis.mechanism` | **yes** | title `<mechanism> · <indication>` |
| `thesis.modality`, `.stage`, `.biomarkers`, `.route` | no | header metadata |
| `recommendation.verdict` | no | copied verbatim; if absent the model chooses from `WriterConfig.allowed_verdicts` |
| `recommendation.confidence` | no | 0..1; shown as % and bar; never generated by the model |
| `capital_to_milestone.{milestone,duration,currency,low,base,high,assumptions}` | no | capital card |
| `sources[]` `{id,title,url,database,identifier,year,authors}` | no | numbered, deduplicated source list (by url → identifier → title, case-insensitive) |
| `analysts[]` `{key,title,status,claims[]}` | no | one section each, in input order |
| `skeptic` `{status,claims[],follow_up_queries[]}` | no | "Skeptic review" section |
| `claims[]` `{id,text,confidence,claim_type,evidence[],related_claim_ids[]}` | `text` | claim cards |
| `evidence[]` `{source_id \| source, stance, excerpt}` | no | supporting / contradicting counts and references |
| `panels.<key>` | no | appendix, rendered verbatim (string, list, or object) |

Notes:

- Supporting and contradicting counts are **derived** by counting `evidence[]`
  items by `stance` (`supporting` / `contradicting`; anything else is neutral).
- References on a claim are the numbered sources of its evidence items.
- `related_claim_ids` on a Skeptic claim links it to the analyst claims it
  challenges, so each analyst section's narrative can address the challenge.
- Only sources cited by at least one claim appear in the source list.
- Expected analyst keys (missing ones raise a warning): `biology`, `clinical`,
  `safety`, `commercial` (`WriterConfig.expected_analysts`).
